Политика конфиденциальности Maestro

Настоящая Политика конфиденциальности определяет, как сервис «Maestro» (далее — «Сервис», «мы») собирает, использует, хранит и раскрывает информацию, полученную от пользователей (далее — «Пользователь», «вы») при использовании Telegram-бота и веб-интерфейса.

1. Какие данные мы собираем

Для работы заявленных функций Сервиса мы обрабатываем следующие категории данных:

  • Для модуля «Поиск TG»: Номера телефонов, никнеймы (@username), ID пользователей Telegram, предоставленные Пользователем.
  • Для модуля «Поиск ТТ»: Никнеймы, URL-адреса профилей или уникальные идентификаторы аккаунтов TikTok.
  • Для модуля «Номер авто»: Государственные регистрационные знаки транспортных средств (ГРЗ).
  • Для модуля «Удаление ТГ»: Идентификаторы аккаунтов, подлежащих блокировке, и контактные данные заявителя для обратной связи.
  • Для модуля «Поиск по лицу»: Биометрические персональные данные в виде загружаемых фотографий (снимков лица).
  • Технические данные: Ваш IP-адрес, тип устройства, время обращения и идентификатор Telegram (для авторизации запросов).

2. Цели сбора данных

Мы не используем ваши данные в рекламных целях. Вся информация обрабатывается исключительно для:

  • Выполнения поисковых запросов через API Telegram и TikTok.
  • Поиска информации о транспортных средствах по государственным базам данных.
  • Формирования и отправки заявок на модерацию и блокировку аккаунтов в Telegram.
  • Проведения биометрической идентификации по загруженному изображению.
  • Обеспечения безопасности Сервиса и предотвращения его использования в незаконных целях.

3. Удаление данных

Мы придерживаемся политики минимального хранения. Запросные данные (номера, фото, ID) автоматически удаляются с наших временных серверов в течение 24 часов после выполнения задачи. Мы не ведем логов поисковых сессий Пользователей дольше указанного срока.

4. Биометрические данные (Поиск по лицу)

Обработка фотографий для модуля «Поиск по лицу» является обработкой биометрических персональных данных. Загружаемые изображения не сохраняются в открытом виде и используются только для сличения с базами данных в момент запроса. Мы не передаем ваши фотографии третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

5. Раскрытие информации

Ваши данные могут быть переданы правоохранительным органам РФ только по официальному, юридически обоснованному запросу (судебное решение, постановление следователя) в рамках проводимых оперативно-розыскных мероприятий.

6. Безопасность

Мы используем современные методы шифрования каналов передачи данных. Однако помните, что ни один метод передачи через интернет не является на 100% безопасным.

7. Согласие пользователя

Используя бота Maestro, вы подтверждаете, что:

  1. Вы имеете законное право на обработку предоставляемых данных (например, являетесь владельцем автомобиля или действуете в интересах следствия).
  2. Вы осознаете, что поиск по открытым источникам (TG, TT) и государственным базам осуществляется на ваш страх и риск.
  3. Вы обязуетесь не использовать Сервис для преследования, шантажа или иных противоправных действий.
